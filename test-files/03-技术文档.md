# MdView 快速上手

## 安装

无需安装，浏览器直接访问。

## 打开文件

1. 点击顶栏「打开 .md」
2. 选择本地文件
3. 右侧即时渲染

## 支持的语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 数学公式

行内：`$E = mc^2$` → $E = mc^2$

独立公式：

```latex
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### 代码块

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"
```

## 导出 PDF

点击右上角「导出 PDF」，在打印对话框选择"另存为 PDF"即可。

## 常见问题

**Q：公式不渲染？**
A：确认使用 `$...$` 包裹，且没有多余空格。

**Q：图片不显示？**
A：本工具不支持本地图片路径，请使用网络图床链接。
