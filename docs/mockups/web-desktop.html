CE-OFDM 相位卷绕

传统 OFDM 的 PAPR 可达 10 ~ 12 dB。CE-OFDM 将信号调制到相位上：

x(t) = A ej(2πfct + 2πh·s(t))

· 恒包络，PAPR = 0 dB
· 接收端相位解卷绕
